# Assets

Everything visible in Lighthouse is built from code (boxes, capsules, spheres and glow
materials), so most of these folders are intentionally empty for now.

| Folder | Contents |
|---|---|
| `logo/` | Project logo (PNG and SVG) |
| `icons/` | Empty. Futuristic interface icons arrive with the polish stage |
| `models/` | Empty. Real 3D models can replace the code-built shapes later |
| `textures/` | Empty. Same idea for textures |
| `fonts/` | Empty. A sci-fi font arrives with the polish stage |

Sound lives in `audio/`:

| Folder | Contents |
|---|---|
| `audio/sfx/` | Placeholder sound effects (generated). Replace any file with a better one of the same name |
| `audio/music/` | Empty. Background music, polish stage |
| `audio/radio/` | Empty. Optional voiced radio lines. Radio text is shown on screen for now |
